The LUSH Data Environment (LDE) — the environment the rest of the work grows from.

Awarded patent ↗ US 12,619,852 B2 ↗

Data modeled as living organic systems.

Most data tools ask you to read. The LDE asks you to look. It maps high-dimensional datasets onto the rules that govern living systems — growth, density, competition, decay — so a shift in the numbers shows up as a shift in an organism you can watch in real time.

The patent covers exactly this: a system for simulating, comparing, and visualising complex data as a living thing.
